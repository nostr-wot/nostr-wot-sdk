First-class authentication for requesters that are not web pages, without changing the web path. `authentication.requesterFor(request, account)` resolves the typed `AuthenticationRequester` a host's transport attested (exclusive with `originFor`; `requesterOf(request.origin)` is the resolver for a host whose transports establish identity before building the request). `authentication.grants` (an `AuthenticationGrantsPort`, satisfied by `Permissions.authentication` or a host store over the same records) makes stored destination consent an explicit opt-in: a stored deny refuses before any prompt for every requester kind; a stored allow skips the prompt and a prompt may answer `site` or `connected-sites` only for a kind in `authentication.rememberFor`, whose default is every kind but `web`; the prompt is told the accepted `scopes` and the `requester` key; a remembered refusal is a destination-scoped deny; the grant is written after every revalidation and the store is re-read after the unlock and after the signature. `authentication.self.requesters` names the host app's own `local` requesters, and `core.handleSelf(request)` signs a NIP-42 login from one of them with no destination prompt and no grant, still subject to the cascade's deny, a stored deny, `assertAllowed`, the unlock and every revalidation; the same requester arriving through `handle` with an authentication event is refused, and NIP-98 is refused on the self path. Activity entries for authentication events carry `authentication: { protocol, destination, method?, requester, consent? }`. A web requester still prompts every time with only `once` accepted unless the host adds `'web'` to `rememberFor`.
